# **App Name**: Cruizr

## Core Features:

- Realm Selection: Allow users to select one of six realms (Professional, Social, Dating, Hook Up, Party/Etc, Ghost) to focus their social discovery.
- GPS-Based User Discovery: Use the device's GPS to display nearby users within the selected realm on a map.
- Smart Matching: Employ a realm-specific matching algorithm that uses machine learning. As a tool, it weighs factors relevant to the user's stated goals to recommend compatible connections within each realm.
- VeilMode™ Privacy Controls: Offer options to blur avatars, hide names, and fuzz locations for enhanced privacy.
- Realm-Specific Safety Protocols: Implement distinct safety measures for each realm, such as mandatory public meetings for dating and health verification for hookups.
- Reporting and Moderation: Provide a system for users to report inappropriate behavior, with community-based moderation for the Party/Etc realm.

## Style Guidelines:

- Primary color: Use a vibrant blue (#29ABE2) to convey trust, communication, and technology, aligning with the app's focus on connection and GPS.
- Background color: Opt for a light gray (#F0F2F5), maintaining a clean and modern aesthetic that complements the dynamic map interface. It is of the same hue as the primary color, but highly desaturated.
- Accent color: Choose a teal color (#22B3A3). Use it to highlight interactive elements and calls to action, to catch the user's attention in a balanced way without overwhelming the map-focused UI.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will give the app a modern and neutral feel. Choose Inter for headlines and body.
- Employ clear and minimalist icons that are distinct for each realm, ensuring easy recognition and navigation. 
- Prioritize a map-centric layout with clear, unobtrusive UI elements, and incorporate smooth transitions between realms.
- Subtle animations and transitions to enhance user experience and provide feedback on interactions, ensuring fluidity and a polished feel.
