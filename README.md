# 🌐 Cruizr - Location-Based Social Discovery Platform

A Next.js full-stack application for intelligent, context-aware social connections.

## ⚡ Quick Start

```bash
npm install
cp .env.example .env.local
# Add your API keys to .env.local
npm run dev
```

Visit http://localhost:9002

## 🚀 Features

- ✅ Multi-realm social discovery (Connect, Social, Dating, Hook Up, Party, Ghost)
- ✅ Interactive map with real-time location
- ✅ AI-powered avatar generation
- ✅ VeilMode™ privacy controls
- ✅ Modern UI with 40+ Radix components
- ✅ Firebase backend ready
- ✅ Production-ready build system

## 🛠️ Tech Stack

- Next.js 15.3.3 + TypeScript
- Firebase (Auth, Firestore, Storage)
- Google Genkit AI (Gemini)
- Mapbox GL
- Tailwind CSS + Radix UI
